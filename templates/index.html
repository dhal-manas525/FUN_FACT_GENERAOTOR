Project Architecture

About FACTVERSE

A modern, responsive full-stack web application designed for exploration and lifelong learning.

Full-Stack Architecture

Powered by a Python Flask REST API with parameterized SQLite database queries, ensuring high performance, zero data leaks, and rapid response times.

Glassmorphic Design

Crafted with modern CSS3 glassmorphism, glowing backdrop filters, responsive mobile drawer navigation, and light/dark theme persistence.

Interactive Features

Features non-repetitive random fact rotation, browser speech synthesis (Text-to-Speech), Web Share API integration, and interactive Quiz Mode.
